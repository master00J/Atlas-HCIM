# Atlas-HCIM op GitHub

Repository: https://github.com/master00J/Atlas-HCIM

De repository bestaat en is openbaar. De volledige broncode, documentatie en bijbehorende assets worden met commits bijgehouden. De geïntegreerde gids bevat Wiki-afgeleid materiaal onder CC BY-NC-SA 3.0; zie ../NOTICE.md.

## Een lokale kopie ophalen

```powershell
git clone https://github.com/master00J/Atlas-HCIM.git
cd Atlas-HCIM
npm test
```

Voor latere aanpassingen: gebruik Git zoals gewoonlijk (`git pull`, aanpassen, `git add`, `git commit`, `git push`). De meegeleverde `PUBLICEER_GITHUB.bat` gebruikt een niet-destructief updatepad en maakt **geen nieuwe repository** aan. Zorg dat je Git en GitHub-authenticatie geconfigureerd hebt.

**Beveiliging:** commit nooit `stream-state.json`, `stream-settings.json`, tokens, persoonlijke accountgegevens of je RuneLite-profiel.
